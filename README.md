# 红色警戒 - 网页版

基于 Godot 4.3 开发的即时战略游戏（RTS），支持 WebAssembly 导出，可在浏览器中直接游玩。

## 游戏特性

- **即时战略玩法** - 建造基地、训练部队、消灭敌人（摧毁对方全部建筑获胜）
- **完整科技树** - 从电厂到雷达，逐级解锁高级建筑和单位，前置依赖检查
- **资源系统** - 采矿车自动采集矿石换取金币（每单位矿石 50 金币）；电力不足时建造速度减半
- **建筑放置** - 网格吸附、邻近己方建筑放置、合法性高亮预览、取消返还造价
- **AI 对手** - 电脑玩家按建造序列自动扩张、生产部队、组织进攻波次
- **程序化地图** - 噪声生成 80x60 大地图（水域/沙地/草地/矿石/岩石/道路），地形影响通行与移速
- **战斗系统** - 投射物弹道、护甲减伤（伤害 = 攻击力 - 护甲）、防御塔自动索敌
- **完整游戏流程** - 主菜单 → 对战 → 胜利/战败/平局 → 重开，含暂停菜单与设置弹窗
- **游戏 HUD** - 金币/电力状态栏、分类建造面板（含队列与进度）、可点击导航的小地图、选中单位信息面板
- **战争迷雾** - 未探索全黑、已探索半暗、视野内清晰，敌方单位仅视野内可见，小地图联动
- **程序化音效** - 射击/爆炸/选择/建造/采矿音效运行时合成，零音频文件
- **工程师占领** - 工程师接近敌方建筑即可占为己有（自身消耗）
- **维修平台** - 自动修理附近友方载具，消耗少量金币
- **难度选择** - 主菜单可选简单/普通/困难，影响 AI 节奏
- **地图大小** - 小/中/大三种尺寸可选，每局随机生成
- **存档系统** - 暂停菜单一键保存，主菜单继续游戏（含实体/经济/迷雾探索状态）
- **背景音乐** - 程序化合成的环境音乐循环，音量可在设置中调节
- **中文界面** - 全中文 UI（内置黑体字体）
- **像素风素材** - 使用 Elite Command 开源素材
- **PWA 支持** - Web 导出启用渐进式 Web 应用，支持离线页面

## 操作方式

| 操作 | 按键 |
|------|------|
| 选择单位/建筑 | 左键点击 |
| 框选多个单位 | 左键拖拽 |
| 移动/攻击 | 右键点击（多单位自动散开列队） |
| 滚动视角 | WASD / 鼠标中键拖拽 / 鼠标边缘（非 Web 平台） |
| 缩放 | 滚轮（0.3x ~ 2.0x） |
| 暂停 | ESC |
| 保存编队 | Ctrl+1~9 |
| 选中编队 | 1~9 |
| 小地图导航 | 左键点击小地图 |
| 放置建筑 | 左键确认 / 右键或 ESC 取消（返还造价） |
| 删除己方单位 | Delete |

## 建筑科技树

```
建造厂 → 电厂 → 兵营 → 机枪碉堡
                → 矿厂 → 战车工厂 → 维修平台
                        → 造船厂（水域）
                        → 雷达 → 导弹碉堡
                               → 机场
```

## 本地运行

### Godot 编辑器
1. 用 Godot 4.3+ 打开项目
2. 按 F5 运行

### Web 导出
```bash
# 需要安装 Godot 4.3+ 和 Web 导出模板
# 方式一：一键构建脚本（Windows）
build_web.bat

# 方式二：手动导出
godot --headless --path . --export-release "Web" export/web/index.html

# 启动本地服务器（自动附带 COOP/COEP 头，WebAssembly 必需）
python serve.py
# 访问 http://localhost:9000
```

## 项目结构

```
├── scripts/
│   ├── autoload/    # 全局单例：游戏状态、音频、设置、单位注册表、字体
│   ├── data/        # 数据表：单位/建筑属性、地图生成与地形规则
│   ├── game/        # 运行时系统：主控、单位、建筑、AI、相机、特效、投射物
│   └── ui/          # 界面：HUD、建造面板、小地图、主菜单、设置弹窗
├── scenes/          # 场景文件（主游戏、主菜单、单位、建筑）
├── assets/          # 精灵图、图标、字体
├── export/web/      # Web 导出产物
├── build_web.bat    # Windows 一键构建脚本
└── serve.py         # 本地预览服务器（COOP/COEP）
```
